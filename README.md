# Secure Stratos – Enterprise SOC & IAM Lab

A hands-on enterprise security lab simulating a real-world organisation using Microsoft security stack.

## Tech Stack
- Microsoft Sentinel
- Microsoft Defender for Endpoint / XDR
- Microsoft Defender for Cloud
- Microsoft Intune
- Microsoft Entra ID (PIM, Conditional Access, RBAC)
- Microsoft 365 E3
- Azure Virtual Machines (Windows Server + Ubuntu)
- Logic Apps (SOAR)

## Lab Structure

| Folder | Contents |
|---|---|
| Architecture-Diagram | Tenant and infrastructure diagrams |
| IAM-RBAC | Role assignments, group structure |
| PIM-Configuration | Eligible roles, activation policies |
| Conditional-Access | CA policy definitions and screenshots |
| Intune-Policies | Compliance and security baseline configs |
| Sentinel-KQL | Analytics rules, hunting queries, workbooks |
| Logic-App-Automation | SOAR playbook definitions |
| Attack-Simulations | Scripts and results from simulated attacks |
| Secure-Score | Baseline and post-hardening score tracking |
| Incident-Reports | Sentinel incident documentation |
| Screenshots | Organised evidence by lab phase |
| PowerShell-Scripts | Automation scripts used throughout the lab |

## Skills Demonstrated
- Tenant administration and multi-user IAM
- RBAC with least privilege model
- Privileged Identity Management (PIM)
- Conditional Access policy design
- Endpoint management via Intune
- SIEM engineering with Microsoft Sentinel
- KQL threat hunting
- SOAR automation via Logic Apps
- Cloud workload security with Defender for Cloud
- Attack simulation and detection validation
